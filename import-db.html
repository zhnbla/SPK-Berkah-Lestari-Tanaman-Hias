🗄️ Import Data dari Database MySQL

Konversi data dari db_tanaman_hias ke localStorage website.

1 Jalankan query ini di phpMyAdmin → tab SQL
SELECT
  t.id,
  t.nama_tanaman,
  t.harga,
  t.stok_sekarang AS stok,
  ROUND(
    (SUM(p.jumlah_terjual) /
      (SELECT MAX(s) FROM (SELECT SUM(jumlah_terjual) s FROM penjualan GROUP BY tanaman_id) mx)
    ) * 9 + 1
  , 0) AS c1_frekuensi,
  ROUND(
    (SUM(pm.jumlah_permintaan) /
      (SELECT MAX(s) FROM (SELECT SUM(jumlah_permintaan) s FROM permintaan GROUP BY tanaman_id) mx)
    ) * 9 + 1
  , 0) AS c2_minat,
  ROUND(
    ((t.stok_awal - t.stok_sekarang) /
      NULLIF((SELECT MAX(v) FROM (SELECT (stok_awal - stok_sekarang) v FROM tanaman) mv), 0)
    ) * 9 + 1
  , 0) AS c4_kecepatan
FROM tanaman t
LEFT JOIN penjualan p ON p.tanaman_id = t.id
LEFT JOIN permintaan pm ON pm.tanaman_id = t.id
GROUP BY t.id, t.nama_tanaman, t.harga, t.stok_sekarang, t.stok_awal
ORDER BY t.id;
✅ Tersalin!
